# BotCommandScopeDefault

Source: https://core.telegram.org/bots/api#botcommandscopedefault

[Documentation index](../llms.txt)

Represents the default [scope](botcommandscope.md) of bot commands. Default commands are used if no commands with a [narrower scope](determining-list-of-commands.md) are specified for the user.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Scope type, must be *default* |
