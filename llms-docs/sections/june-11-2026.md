# June 11, 2026

Source: https://core.telegram.org/bots/api#june-11-2026

[Documentation index](../llms.txt)

**Bot API 10.1**

**Rich Messages**

- Added support for [Rich Messages](https://core.telegram.org/bots/features#rich-messages), allowing bots to send highly structured text and stream AI-generated replies with seamless rich formatting.
- Added the classes [RichTextBold](richtextbold.md), [RichTextItalic](richtextitalic.md), [RichTextUnderline](richtextunderline.md), [RichTextStrikethrough](richtextstrikethrough.md), [RichTextSpoiler](richtextspoiler.md), [RichTextDateTime](richtextdatetime.md), [RichTextTextMention](richtexttextmention.md), [RichTextSubscript](richtextsubscript.md), [RichTextSuperscript](richtextsuperscript.md), [RichTextMarked](richtextmarked.md), [RichTextCode](richtextcode.md), [RichTextCustomEmoji](richtextcustomemoji.md), [RichTextMathematicalExpression](richtextmathematicalexpression.md), [RichTextUrl](richtexturl.md), [RichTextEmailAddress](richtextemailaddress.md), [RichTextPhoneNumber](richtextphonenumber.md), [RichTextBankCardNumber](richtextbankcardnumber.md), [RichTextMention](richtextmention.md), [RichTextHashtag](richtexthashtag.md), [RichTextCashtag](richtextcashtag.md), [RichTextBotCommand](richtextbotcommand.md), [RichTextAnchor](richtextanchor.md), [RichTextAnchorLink](richtextanchorlink.md), [RichTextReference](richtextreference.md) and [RichTextReferenceLink](richtextreferencelink.md), which represent different types of rich formatted text.
- Added the class [RichText](richtext.md), which represents rich formatted text.
- Added the class [RichBlockCaption](richblockcaption.md), which represents the caption of a rich formatted text.
- Added the class [RichBlockTableCell](richblocktablecell.md), which represents a cell in a table.
- Added the class [RichBlockListItem](richblocklistitem.md), which represents an item in a list.
- Added the classes [RichBlockParagraph](richblockparagraph.md), [RichBlockSectionHeading](richblocksectionheading.md), [RichBlockPreformatted](richblockpreformatted.md), [RichBlockFooter](richblockfooter.md), [RichBlockDivider](richblockdivider.md), [RichBlockMathematicalExpression](richblockmathematicalexpression.md), [RichBlockAnchor](richblockanchor.md), [RichBlockList](richblocklist.md), [RichBlockBlockQuotation](richblockblockquotation.md), [RichBlockPullQuotation](richblockpullquotation.md), [RichBlockCollage](richblockcollage.md), [RichBlockSlideshow](richblockslideshow.md), [RichBlockTable](richblocktable.md), [RichBlockDetails](richblockdetails.md), [RichBlockMap](richblockmap.md), [RichBlockAnimation](richblockanimation.md), [RichBlockAudio](richblockaudio.md), [RichBlockPhoto](richblockphoto.md), [RichBlockVideo](richblockvideo.md), [RichBlockVoiceNote](richblockvoicenote.md) and [RichBlockThinking](richblockthinking.md), which represent different types of blocks in a rich formatted message.
- Added the class [RichBlock](richblock.md), which represents a block in a rich formatted message.
- Added the class [RichMessage](richmessage.md), which represents a rich formatted message.
- Added the field *rich_message* to the class [Message](message.md).
- Added the class [InputRichMessage](inputrichmessage.md), describing a rich message to send.
- Added the class [InputRichMessageContent](inputrichmessagecontent.md) and allowed it to be used as [InputMessageContent](inputmessagecontent.md) in results of inline, guest, and Web App queries.
- Added the method [sendRichMessage](sendrichmessage.md), allowing bots to send rich messages.
- Added the method [sendRichMessageDraft](sendrichmessagedraft.md), allowing bots to stream partial rich messages.
- Added the parameter *rich_message* to the method [editMessageText](editmessagetext.md), allowing bots to edit rich messages.

**Join Request Queries**

- Added the field *supports_join_request_queries* to the class [User](user.md).
- Added the field *guard_bot* to the class [ChatFullInfo](chatfullinfo.md).
- Added the field *query_id* to the class [ChatJoinRequest](chatjoinrequest.md).
- Added the method [answerChatJoinRequestQuery](answerchatjoinrequestquery.md).
- Added the method [sendChatJoinRequestWebApp](sendchatjoinrequestwebapp.md).

**Polls**

- Added the class [Link](link.md) and the field *link* to the class [PollMedia](pollmedia.md).
- Added the class [InputMediaLink](inputmedialink.md) and allowed it to be used as [InputPollOptionMedia](inputpolloptionmedia.md).
