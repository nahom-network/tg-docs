# Telegram Passport

Source: https://core.telegram.org/bots/api#telegram-passport

[Documentation index](../llms.txt)

**Telegram Passport** is a unified authorization method for services that require personal identification. Users can upload their documents once, then instantly share their data with services that require real-world ID (finance, ICOs, etc.). Please see the [manual](../external/passport.md) for details.
