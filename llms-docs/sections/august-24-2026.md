# August 24, 2026

Source: https://core.telegram.org/bots/api#august-24-2026

[Documentation index](../llms.txt)

**Bot API 10.3**

**Rich Messages**

- Added the class [RichMessageButton](richmessagebutton.md) representing a button in a [RichMessage](richmessage.md).
- Added the class [RichTextButton](richtextbutton.md).
- Added the classes [RichBlockButtons](richblockbuttons.md) and [InputRichBlockButtons](inputrichblockbuttons.md).
- Added the field *is\_compact* to the classes [RichBlockTable](richblocktable.md) and [InputRichBlockTable](inputrichblocktable.md).
- Added the classes [RichBlockExpandableBlockQuotation](richblockexpandableblockquotation.md) and [InputRichBlockExpandableBlockQuotation](inputrichblockexpandableblockquotation.md) representing a block quotation, which can be expanded or collapsed back.
- Added the classes [RichBlockDocument](richblockdocument.md) and [InputRichBlockDocument](inputrichblockdocument.md), containing a file.
- Added support for links of the form `tg://document?id=` for general file uploads in rich messages.

**Ephemeral messages**

- Added the class [EphemeralMessageParameters](ephemeralmessageparameters.md) and replaced the parameters *receiver\_user\_id* and *callback\_query\_id* in the methods [sendMessage](sendmessage.md), [sendAnimation](sendanimation.md), [sendAudio](sendaudio.md), [sendDocument](senddocument.md), [sendLivePhoto](sendlivephoto.md), [sendPhoto](sendphoto.md), [sendSticker](sendsticker.md), [sendVideo](sendvideo.md), [sendVideoNote](sendvideonote.md), [sendVoice](sendvoice.md), [sendContact](sendcontact.md), [sendLocation](sendlocation.md) and [sendVenue](sendvenue.md) with the parameter *ephemeral\_message\_parameters*.
- Added the parameter *ephemeral\_message\_parameters* to the method [sendRichMessage](sendrichmessage.md).
- Added the field *replace\_callback\_query\_message* to the class [EphemeralMessageParameters](ephemeralmessageparameters.md), which allows bots to show an ephemeral message in place of the original message.
- Supported upload of new files in [editEphemeralMessageMedia](editephemeralmessagemedia.md).
- Added the parameter *show\_caption\_above\_media* to the method [editEphemeralMessageCaption](editephemeralmessagecaption.md).
- Added the parameter *rich\_message* to the method [editEphemeralMessageText](editephemeralmessagetext.md).
- Added the field *can\_send\_welcome\_messages* to the classes [ChatAdministratorRights](chatadministratorrights.md) and [ChatMemberAdministrator](chatmemberadministrator.md).
- Added the parameter *can\_send\_welcome\_messages* to the method [promoteChatMember](promotechatmember.md).

**Reply markup**

- Added the class [DisabledButton](disabledbutton.md) and the field *disabled* to the class [InlineKeyboardButton](inlinekeyboardbutton.md).
- Added the field *force\_reply* to the classes [InlineKeyboardMarkup](inlinekeyboardmarkup.md) and [ReplyKeyboardMarkup](replykeyboardmarkup.md).

**General**

- Added the parameters *can\_stop* and *keep\_on\_stop* to the methods [sendMessageDraft](sendmessagedraft.md) and [sendRichMessageDraft](sendrichmessagedraft.md).
- Added updates about user stopping message generation, represented by the class [MessageGenerationStopped](messagegenerationstopped.md) and the field *stopped\_message\_generation* in the class [Update](update.md).
- Added the class [CommunityChatJoined](communitychatjoined.md) and the field *community\_chat\_joined* to the class [Message](message.md) for service messages about join of a chat from a community.
- Added the fields *text*, *entities* and *is\_private* to the class [UniqueGiftInfo](uniquegiftinfo.md).
