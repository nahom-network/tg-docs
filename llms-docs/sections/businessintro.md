# BusinessIntro

Source: https://core.telegram.org/bots/api#businessintro

[Documentation index](../llms.txt)

Contains information about the start page settings of a Telegram Business account.

| Field   | Type                                                  | Description                                    |
| ------- | ----------------------------------------------------- | ---------------------------------------------- |
| title   | String                                                | *Optional*. Title text of the business intro   |
| message | String                                                | *Optional*. Message text of the business intro |
| sticker | [Sticker](sticker.md) | *Optional*. Sticker of the business intro      |
