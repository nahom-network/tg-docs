# UniqueGiftSymbol

Source: https://core.telegram.org/bots/api#uniquegiftsymbol

[Documentation index](../llms.txt)

This object describes the symbol shown on the pattern of a unique gift.

| Field | Type | Description |
| --- | --- | --- |
| name | String | Name of the symbol |
| sticker | [Sticker](sticker.md) | The sticker that represents the unique gift |
| rarity\_per\_mille | Integer | The number of unique gifts that receive this model for every 1000 gifts upgraded |
