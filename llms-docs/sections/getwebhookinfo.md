# getWebhookInfo

Source: https://core.telegram.org/bots/api#getwebhookinfo

[Documentation index](../llms.txt)

Use this method to get current webhook status. Requires no parameters. On success, returns a [WebhookInfo](webhookinfo.md) object. If the bot is using [getUpdates](getupdates.md), will return an object with the *url* field empty.
