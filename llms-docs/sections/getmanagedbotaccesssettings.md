# getManagedBotAccessSettings

Source: https://core.telegram.org/bots/api#getmanagedbotaccesssettings

[Documentation index](../llms.txt)

Use this method to get the access settings of a managed bot. Returns a [BotAccessSettings](botaccesssettings.md) object on success.

| Parameter | Type    | Required | Description                                                               |
| --------- | ------- | -------- | ------------------------------------------------------------------------- |
| user_id   | Integer | Yes      | User identifier of the managed bot whose access settings will be returned |
