# PaidMediaInfo

Source: https://core.telegram.org/bots/api#paidmediainfo

[Documentation index](../llms.txt)

Describes the paid media added to a message.

| Field | Type | Description |
| --- | --- | --- |
| star\_count | Integer | The number of Telegram Stars that must be paid to buy access to the media |
| paid\_media | Array of [PaidMedia](paidmedia.md) | Information about the paid media |
