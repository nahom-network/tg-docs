# getMyName

Source: https://core.telegram.org/bots/api#getmyname

[Documentation index](../llms.txt)

Use this method to get the current bot name for the given user language. Returns [BotName](botname.md) on success.

| Parameter     | Type   | Required | Description                                             |
| ------------- | ------ | -------- | ------------------------------------------------------- |
| language_code | String | Optional | A two-letter ISO 639-1 language code or an empty string |
