# May 8, 2026

Source: https://core.telegram.org/bots/api#may-8-2026

[Documentation index](../llms.txt)

**Bot API 10.0**

**Guest Mode**

- Introduced support for [guest mode](https://core.telegram.org/bots/features#guest-bots), allowing bots to receive certain messages and issue replies within chats they are not a member of.
- Added the field *supports_guest_queries* to the class [User](user.md).
- Added the fields *guest_bot_caller_user* and *guest_bot_caller_chat* to the class [Message](message.md).
- Added the field *guest_query_id* to the class [Message](message.md).
- Added the field *guest_message* to the class [Update](update.md).
- Added the class [SentGuestMessage](sentguestmessage.md) and the method [answerGuestQuery](answerguestquery.md).

**Chat Management**

- Added the field *can_react_to_messages* to the classes [ChatMemberRestricted](chatmemberrestricted.md) and [ChatPermissions](chatpermissions.md).
- Added the parameter *return_bots* to the method [getChatAdministrators](getchatadministrators.md).
- Added the method [deleteAllMessageReactions](deleteallmessagereactions.md).
- Added the method [deleteMessageReaction](deletemessagereaction.md).
- Added the ability to see certain messages sent by other bots in groups.

**Polls**

- Added the classes [InputMediaSticker](inputmediasticker.md), [InputMediaLocation](inputmedialocation.md), and [InputMediaVenue](inputmediavenue.md).
- Added the class [PollMedia](pollmedia.md), representing a media in a poll.
- Added the field *media* to the class [Poll](poll.md), allowing bots to see media in polls.
- Added the field *explanation_media* to the class [Poll](poll.md), allowing bots to see media in quiz explanations.
- Added the field *media* to the class [PollOption](polloption.md), allowing bots to see media in poll options.
- Added the class [InputPollMedia](inputpollmedia.md) and the parameters *media* and *explanation_media* to the method [sendPoll](sendpoll.md), allowing bots to add media to polls.
- Added the class [InputPollOptionMedia](inputpolloptionmedia.md) and the field *media* to the class [InputPollOption](inputpolloption.md), allowing bots to add media to poll options.
- Added the field *members_only* to the class [Poll](poll.md).
- Added the parameter *members_only* to the method [sendPoll](sendpoll.md).
- Added the field *country_codes* to the class [Poll](poll.md).
- Added the parameter *country_codes* to the method [sendPoll](sendpoll.md).
- Decreased the minimum number of poll options from 2 to 1.

**Live photos**

- Added the class [LivePhoto](livephoto.md), which represents a photo with a short video.
- Added the class [InputMediaLivePhoto](inputmedialivephoto.md).
- Added the field *live_photo* to the classes [Message](message.md) and [ExternalReplyInfo](externalreplyinfo.md).
- Added the method [sendLivePhoto](sendlivephoto.md), allowing bots to send live photos.
- Added the class [PaidMediaLivePhoto](paidmedialivephoto.md), which describes a paid media with a live photo.
- Added the class [InputPaidMediaLivePhoto](inputpaidmedialivephoto.md), allowing bots to send live photos as paid media.
- Allowed to use live photos in [sendMediaGroup](sendmediagroup.md) and [editMessageMedia](editmessagemedia.md),

**General**

- Allowed [Secretary Bots](https://core.telegram.org/bots/features#secretary-bots) to manage accounts of users without a Telegram Premium subscription.
- Added the ability to send messages to other bots via username if both bots enabled bot-to-bot communication.
- Added the ability to reply to other bots from a business bot if the business bot enabled bot-to-bot communication.
- Allowed bots to pass an empty text in the method [sendMessageDraft](sendmessagedraft.md).
- Added the class [BotAccessSettings](botaccesssettings.md) and the method [getManagedBotAccessSettings](getmanagedbotaccesssettings.md).
- Added the method [setManagedBotAccessSettings](setmanagedbotaccesssettings.md).
- Added the method [getUserPersonalChatMessages](getuserpersonalchatmessages.md).
