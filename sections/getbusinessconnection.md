# getBusinessConnection

Source: https://core.telegram.org/bots/api#getbusinessconnection

[Documentation index](../llms.txt)

Use this method to get information about the connection of the bot with a business account. Returns a [BusinessConnection](businessconnection.md) object on success.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| business_connection_id | String | Yes | Unique identifier of the business connection |
