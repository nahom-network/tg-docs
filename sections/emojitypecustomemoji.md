A custom emoji.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Type of the emoji, always “custom\_emoji” |
| custom\_emoji\_id | String | Identifier of the custom emoji. Use [getCustomEmojiStickers](getcustomemojistickers.md) to get full information about the sticker. |
