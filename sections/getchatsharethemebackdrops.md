# getChatShareThemeBackdrops

Source: https://core.telegram.org/bots/api#getchatsharethemebackdrops

[Documentation index](../llms.txt)

Use this method to get the list of backdrops, which can be used as the background of a theme of the screen for sharing a link to a user or a chat. Requires no parameters. Returns a [ChatShareThemeBackdrops](chatsharethemebackdrops.md) object.
