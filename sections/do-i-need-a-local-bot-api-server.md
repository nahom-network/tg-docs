# Do I need a Local Bot API Server

Source: https://core.telegram.org/bots/api#do-i-need-a-local-bot-api-server

[Documentation index](../llms.txt)

The majority of bots will be OK with the default configuration, running on our servers. But if you feel that you need one of [these features](using-a-local-bot-api-server.md), you're welcome to switch to your own at any time.
