The SDK

The SDKAt runtime a module has one library: sdk. It bundles the three things a bot backend needs — a database, the Telegram Bot API, and outbound HTTP — with nothing to install and no credentials to configure. The database (db)↗The Bot APIapi gives you the entire Telegram Bot API. Call any method as api.<method>(params). Every current — and future — Bot API method works with no SDK update required.↗HTTPfetch is a fetch‑like client for calling the outside world — third‑party APIs, webhooks, anything over HTTP.↗LoggingThe standard global console is available — nothing to import, it's just there as in any JavaScript. Its output is captured and shown by npx tgcloud run, which makes it your primary debugging tool during development.↗
